# Flora Vision AR

Filter wajah AR berbasis [MediaPipe Face Mesh](https://google.github.io/mediapipe/)
— murni browser, tanpa backend.

## Tech
- MediaPipe `camera_utils` + `face_mesh`
- Canvas 2D untuk overlay
- Vanilla JS + CSS (fonts: Cormorant Garamond + Quicksand)

## Cara pakai
Buka `index.html` lewat HTTPS atau `localhost` (kamera butuh secure context).
Izinkan akses kamera → overlay langsung tampil di wajah.
